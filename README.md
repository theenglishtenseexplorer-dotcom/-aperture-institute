# APERTURE Institute Website

Complete multi-page static website built with the APERTURE Institute brand identity and copy.

## Structure
- `index.html` — Homepage
- `about.html` — About Us (Why APERTURE?, Vision, Mission, Core Values, Educational Approach)
- `programs.html` — Programs Overview (4 Academic Divisions)
- `programs/english.html` — 01 APERTURE English
- `programs/examination-preparation.html` — 02 Examination Preparation
- `programs/professional.html` — 03 APERTURE Professional
- `programs/educator-development.html` — 04 Educator Development
- `learning-experience.html` — Live Online Learning, Self-Paced Learning & 5-Step Journey
- `faqs.html` — Categorized Frequently Asked Questions
- `contact.html` — Inquiry Form & Privacy Notice Placeholder
- `assets/css/style.css` — Shared responsive stylesheet
- `assets/js/main.js` — Navigation menu & form preview handler
